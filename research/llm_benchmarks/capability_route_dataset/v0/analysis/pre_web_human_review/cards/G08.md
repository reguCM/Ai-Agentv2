### **2. 音量ピークの取得方法**
#### **(1) AudioWorkletでリアルタイム処理**
- **AudioWorklet**は、音声処理に特化したスレッドで動作し、リアルタイム処理に適しています。
- **AudioBuffer**からサンプルデータを取得し、最大値（ピーク）を計算します。

#### **(2) ScriptProcessorNode（非推奨）**
- 過去のAPIで、`ScriptProcessorNode`を使用して音声を処理できますが、**非推奨**（パフォーマンス低下のリスクあり）。
- 代替として、**AudioWorklet**を推奨します。

---

### **3. AudioWorkletの実装例**
#### **(1) worklet.processor.js**
```javascript
class PeakDetector {
  constructor() {
    this.maxPeak = 0;
  }

  process(input, output) {
    const buffer = input[0];
    let peak = 0;
    for (let i = 0; i < buffer.length; i++) {
      const sample = buffer[i];
      if (Math.abs(sample) > peak) {
        peak = Math.abs(sample);
      }
    }
    this.maxPeak = Math.max(this.maxPeak, peak);
    // メインスレッドに結果を送信
    this.port.postMessage({ peak: this.maxPeak });
  }
}

registerProcessor("peak-detector", PeakDetector);
```

#### **(2) メインスレッドでの設定**
```javascript
const audioContext = new AudioContext();
const worklet = audioContext.createAudioWorkletNode("peak-detector");

worklet.port.onmessage = (event) => {
  const peak = event.data.peak;
  console.log("リアルタイム音量ピーク:", peak);
};
```

---

### **4. 注意点**

- **ブラウザの制限**（例: ChromeではAudioWorkletが必須）に注意し、互換性を確認してください。
