母艦のUPS（Uninterruptible Power Supply）残量パーセントを取得する方法は、以下の通りです。ただし、具体的なシステムや環境によって手順が異なる場合があります。

---

### **1. ハードウェア・ソフトウェアの確認**
- **UPSの種類**:  
  - バッテリー内蔵型UPS（例：サーバー用UPS）  
  - 外部バッテリー型UPS（例：コンピュータの電源ユニット）  
  - 宇宙船や船舶用の専用UPS（仮想的なシナリオ）  

- **OSの種類**:  
  - Windows / macOS / Linux / その他  

---

### **2. 一般的な方法（コンピュータ用UPS）**
#### **Windows**
1. **コマンドプロンプト**を開き、以下を実行:  
   ```bash
   powercfg -batteryinfo
   ```
   - 出力結果から「バッテリーの残量（%）」を確認。  
   - または、**設定 > システム > バッテリー**で直接確認可能。

2. **UPS管理ソフト**を使用:  
   - 例: APC UPSの場合は、APCの管理ソフト（APCViewなど）で確認。

#### **macOS**
1. **ターミナル**で以下を実行:  
   ```bash
   pmset -g batt
   ```
   - 出力結果から「%」の値を確認。

2. **Third-partyツール**（例: iStat Menus）でリアルタイム表示。

#### **Linux**
1. **`upower`コマンド**を使用:  
   ```bash
   upower -i /org/freedesktop/UPower/devices/DisplayDevice
   ```
   - `Percentage`フィールドを確認。

2. **`acpi`コマンド**（一部のシステムで有効）:  
   ```bash
   acpi -b
   ```

---

### **3. 宇宙船/船舶用UPS（仮想シナリオ）**
- **操作パネル**や**監視システム**に接続し、バッテリー残量を直接確認。  
- **APIやコマンドラインインターフェース**（CLI）で取得する場合、システム固有のコマンドが必要。

---

### **4. 注意点**
- **不確かな点**:  
  - 「母艦」という表現は、宇宙船や船舶を指す可能性があるが、具体的なシステムが不明。  
  - UPSの種類やOSの詳細が分からない場合、正確な手順は特定できない。  
- **推測**:  
  - 実際の宇宙船や船舶では、専用の監視システムやコマンドが用意されている可能性が高い。

---

### **5. 代替案**
- **物理的な確認**:  
  - UPSの表示ランプやディスプレイを直接確認。  
- **ログファイルの確認**:  
  - システムのログ（例: `/var/log/`）に残量情報が記録されている場合あり。

---

**補足**: 上記は一般的な方法です。特定のシステムや環境では異なる手順が必要になる場合があります。詳細な情報（OS、UPSのメーカー、用途など）があれば、より正確なアドバイスが可能です。
