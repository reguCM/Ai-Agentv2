### **1. 一般的なツール（最近も安定して利用可能）**

  - 詳細な温度・電圧・クロック情報が取得可能。

- **Core Temp**  
  - Intel CPUの温度をリアルタイムで表示。  
  - シンプルなインターフェースで、初心者にも親しみやすい。  
  - 2023年現在も更新が続いており、最新のIntelプロセッサに対応。

  - オープンソースで、温度・電圧・ファン速度を監視。  
  - Windows 10/11でも動作し、グラフィカルな表示が可能。  
  - GitHubなどで最新バージョンが入手可能。

- **Thermal Monitoring Tools（AMD/Ryzen向け）**  
  - AMDのRyzen CPUには、**Ryzen Master**や**AMD Ryzen System Monitor**が提供される。  
  - 2023年現在も更新が行われており、温度監視に特化。

### **2. Windowsのビルトインツール**

- **PowerShellスクリプト**  
  - WMIやOpen Hardware MonitorのAPIを組み合わせて、温度を取得するスクリプトが存在するが、**複数のステップが必要**で、初心者には敷居が高い。

## 4. 最終回答

```text
WindowsのCPU温度取得に関しては、現在の環境（Python 3.14 / Windows）では`cpu_status`関数が提供する情報が限られており、温度データの取得は対応していません。また、Web検索でも最新の方法やツールに関する情報は取得できませんでした。

**対応策として以下が考えられます**:
1. **専用ソフトウェアの利用**:  
   - Core Temp, HWMonitor, Open Hardware Monitorなどのツールで確認可能（Windows専用）。
   - PowerShellスクリプトやWMIコマンドでも取得可能（技術的な知識が必要）。

2. **Linux系のツール（WSL）**:  
   - `sensors`や`lm-sensors`で温度取得可能（Windows 10/11のWSL2環境で利用可能）。

3. **BIOS/UEFI画面**:  
   - マシンの起動画面や設定画面で直接確認可能。

ただし、ローカル環境の制約上、これらのツールや方法は`search_web`や`cpu_status`で直接実行できません。必要に応じて、手動で上記の方法を検討してください。
```
