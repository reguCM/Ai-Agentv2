~~~~text
import requests
from bs4 import BeautifulSoup

def web_search(query, url="https://example.com"):
    try:
        # HTTPリクエスト送信
        response = requests.get(url, params={"q": query}, timeout=10)
        response.raise_for_status()  # エラーがあれば例外をスロー

        # HTMLコンテンツを解析
        soup = BeautifulSoup(response.text, "html.parser")

        # 検索結果を抽出（例: <div class="result">内のテキスト）
        results = soup.find_all("div", class_="result")
        extracted_data = [result.get_text(strip=True) for result in results]

        return extracted_data

    except requests.exceptions.RequestException as e:
        print(f"ネットワークエラー: {e}")
        return []
    except Exception as e:
        print(f"予期せぬエラー: {e}")
        return []
```
~~~~

~~~~text
### **2. 音量ピークの取得方法**
#### **(1) AudioWorkletでリアルタイム処理**

#### **(2) ScriptProcessorNode（非推奨）**
- 過去のAPIで、`ScriptProcessorNode`を使用して音声を処理できますが、**非推奨**（パフォーマンス低下のリスクあり）。

### **3. AudioWorkletの実装例**
#### **(1) worklet.processor.js**
```javascript
class PeakDetector {
  constructor() {
    this.maxPeak = 0;
  }

  process(input, output) {
    const buffer = input[0];
    let peak = 0;
    for (let i = 0; i < buffer.length; i++) {
      const sample = buffer[i];
      if (Math.abs(sample) > peak) {
        peak = Math.abs(sample);
      }
    }
    this.maxPeak = Math.max(this.maxPeak, peak);
    // メインスレッドに結果を送信
    this.port.postMessage({ peak: this.maxPeak });
  }
}

registerProcessor("peak-detector", PeakDetector);
```

#### **(2) メインスレッドでの設定**
```javascript
const audioContext = new AudioContext();
const worklet = audioContext.createAudioWorkletNode("peak-detector");

worklet.port.onmessage = (event) => {
  const peak = event.data.peak;

};
~~~~
