# 人間レビュー選択肢（再構成後）

「どちらを採用するか」は評価しない。差分観測用。

## question_clarity（質問の明確さ）

| 値 | 意味 |
|----|------|
| ◎ 明確 | 要求の意図がはっきりしている |
| ○ ほぼ明確 | おおむね通るが細部は曖昧 |
| △ 曖昧 | 解釈が複数ありうる |
| × 意味が破綻している | 質問自体が成立しにくい（元requestは変更しない） |

## web_without_answer_quality（Webなし回答の十分性）

Webありとの優劣ではなく、**単体品質**。

| 値 | 意味 |
|----|------|
| ◎ 十分 | そのまま返してよい |
| ○ 概ね十分 | 大きな欠落はない |
| △ 情報不足 | 不足が目立つ |
| × 明確な問題あり | 誤り・空疎・破綻など |

## search_result_usefulness（検索結果の有用性）

| 値 | 意味 |
|----|------|
| ◎ 非常に有用 | 回答に直結 |
| ○ 有用 | 使える |
| △ 一部有用 | 一部だけ |
| × 無関係・取得失敗 | 使えない／失敗 |
