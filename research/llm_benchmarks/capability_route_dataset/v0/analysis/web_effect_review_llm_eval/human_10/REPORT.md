## 最終8問への回答

### 1. Qwen3:8Bは人間の個別評価とどの程度一致したか？

検索有用性（Q2）は**方向として近い（近似込み100%）**が、ラベル完全一致は低い（10%）。採用先（導出Q5）は比較可能な範囲で高め（≈83%）。Q3は44%と揺れが大きい。Q1は人間スキーマに無いため未算出。

### 2. 検索結果そのものの有用性を評価できたか？

本文なし多数セットでは、概ね「役に立たない／判断不能」側に寄せており、**タイトルだけで◎にする誤りは今回の10件では目立たない**。一方、人間の「― 検索失敗・比較不能」とLLMの「×」は意味が近くてもラベルは異なる。

### 3. 「Webなしでも十分」と「検索機能が弱い」を区別できたか？

P02a/A06等では区別できている（Webなし十分＋検索失敗）。C02では人間が「検索は役立つが英語」、Qwenが「補完あり→Webあり」と**検索品質問題の見え方がずれる**。区別は部分的。

### 4. 「現在・最新」など時間依存性を適切に認識したか？

**不十分。** 特に A03（「最近」）で人間はWebなし不可、Qwen Q1は「なくてもよい」。A04/C04では必要性○を出せるが、安定していない。SELF_CHECKでも時間依存認識が False のケースあり（P02a/P02b/A03）。

### 5. 検索結果の問題を正しく原因として認識できたか？

大枠（本文取得失敗・検索空）は多くのケースで認識。ただし「質問曖昧さ」（C03/A04）や「英語理解」（C02）など、人間が強調する副次原因は取りこぼしやすい。

### 6. 「次に何を修正すべきか」で一致したか？

**弱い（完全一致0%、部分一致50%）。** セル一致が高くても、ここが低いなら評価器委任は尚早、という今回の判定基準に抵触する。

### 7. 一致率90%以上を目指して評価器として任せられる状態に近いか？

**いいえ（現時点）。** n=10の予備検証であり、近似込みの高い数字だけを見て十分とは断定しない。重視指標の **D（改善方針）完全一致0%** と **時間依存の重大ズレ（A03）** があるため、一次評価器として任せる段階ではない。追加検証やプロンプト改善の検討対象。

### 8. まだ人間によるレビューが必要な領域は何か？

1. 時間依存質問で検索が空のときの「必要だが失敗」判断  
2. 質問意味の破綻・曖昧さ（C03等）  
3. 結論一致でも原因が違うケースの解釈  
4. Q7の修正優先順位（何を直すか）
