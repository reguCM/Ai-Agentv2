# 実験プロトコル v1

実装仕様ではない。測りたい問題解決プロセスの基準である。採用した FA / Schema / Repair 変更ではない。

---

## 流れ

```
Failure発生
  ↓
【初期Failure】最小限の情報を LLM へ渡す
  ↓
【LLM判断】
  ├─ 追加情報不要 → 修正案
  └─ 情報不足 → Tool選択 → Tool実行 → Tool結果 → LLM再判断
                    ├─ 追加調査 → Tool実行 …
                    └─ 修正案 → Sandbox Test → Test結果 → LLM
                         ├─ 解決
                         ├─ 再調査
                         └─ HELP
```

後から実験結果だけで、各矢印の入力・出力・主体を追跡できること。

---

## 段階の意味（混同しない）

| 段階 | 意味 |
| --- | --- |
| 初期Failure | 必要以上を最初から渡さない |
| Tool提示 | LLM が利用可能な Tool を認識できる |
| Tool選択 | LLM 自身が選ぶ。Dispatcher 実行とは別 |
| Tool実行 | 要求された name/args で handler が走る |
| Tool結果 | その結果だけを LLM へ返し再判断させる |
| 修正案 | 情報十分と判断したときの案。適用は別 |
| Sandbox Test | 安全な隔離実行 |
| Test判定 | 実行成功と解決を同一視しない |
| Test再投入 | Test 結果を LLM が見て分岐する |
| HELP | 安全に判断できない、を記録できる |
| ログ | 結果 JSON から過程を再構成できる |
