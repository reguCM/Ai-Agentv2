### 3. テトロミノの形状定義
**質問:** テトロミノの形状をどのように定義しますか？  
**推奨回答:**  
```python
# テトロミノの形状（例: I, O, T, S, Z, J, L）
SHAPES = {
    'I': [[1,1,1,1]],
    'O': [[1,1],[1,1]],
    'T': [[0,1,0],[1,1,1]],
    'S': [[0,1,1],[1,1,0]],
    'Z': [[1,1,0],[0,1,1]],
    'J': [[1,0,0],[1,1,1]],
    'L': [[0,0,1],[1,1,1]]
}

# ランダムなテトロミノ生成
def get_random_tetromino():
    shape = random.choice(list(SHAPES.keys()))
    return {
        'shape': SHAPES[shape],
        'color': (random.randint(0,255), random.randint(0,255), random.randint(0,255))
    }
```

### 4. テトロミノの初期配置と移動
**質問:** テトロミノを画面中央上部に配置する方法は？  
**推奨回答:**  
```python
# テトロミノの初期位置（グリッドの上部中央）
def create_tetromino():
    tetromino = get_random_tetromino()
    return {
        'x': GRID_WIDTH // 2 - len(tetromino['shape'][0]) // 2,
        'y': 0,
        'shape': tetromino['shape'],
        'color': tetromino['color']
    }

# テトロミノの描画
def draw_tetromino(tetromino):
    for y, row in enumerate(tetromino['shape']):
        for x, cell in enumerate(row):
            if cell:
                pygame.draw.rect(screen, tetromino['color'], 
                                 (tetromino['x']*BLOCK_SIZE + x*BLOCK_SIZE, 
                                  tetromino['y']*BLOCK_SIZE + y*BLOCK_SIZE, 
                                  BLOCK_SIZE, BLOCK_SIZE))
```

### 5. 衝突判定の実装
**質問:** テトロミノの移動時に衝突を判定するロジックは？  
**推奨回答:**  
```python
def check_collision(tetromino, grid, dx=0, dy=0):
    for y, row in enumerate(tetromino['shape']):
        for x, cell in enumerate(row):
            if cell:
                nx = tetromino['x'] + x + dx
                ny = tetromino['y'] + y + dy
                if nx < 0 or nx >= GRID_WIDTH or ny >= GRID_HEIGHT:
                    return True
                if ny >= 0 and grid[ny][nx]:
                    return True
    return False
```
